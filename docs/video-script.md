## 失败重录判据（每景问一遍）

1. 流式是逐句出现还是整段弹出？（整段=重录）
2. 路线画线是否贴走廊？（飘进店铺=底图坐标问题，查 svgCoords）
3. trace 步骤时延是否全 0？（全 0=还在跑旧镜像，重部署）
4. 改营业时间后再问，结果是否真的变了？（没变=内容服务缓存/多租户过滤问题）
