# 简历项目块 · SAGE（复制即用）

## 项目名（一行）

**SAGE — 场景无关的空间智能体导视平台**（个人全栈作品 · 已公网上线）
`sage.westwardecho.com` · `github.com/WenYu0306/sage-spatial-agent-guidance-engine`

## 一句话简介（二选一）

- 完整版：基于 LangGraph 的多租户空间智能体导视平台——自然语言问答、跨楼层路径规划、pgvector 知识检索、推荐排序与运营后台，微服务架构，已部署公网完整体验。
- 精简版：AI 空间导视平台（Agent 编排 + RAG + 路径引擎 + 运营后台），公网可体验，换场景代码零改动。

## 技术栈行

Python 3.12 · FastAPI · LangGraph · PostgreSQL/pgvector · Redis · React 19 · TypeScript · Tailwind v4 · Docker/compose · GitHub Actions · Nginx

## 要点（STAR，按岗位侧重取舍 3-5 条）

1. **【架构】设计"场景无关"空间智能体内核**：空间计算沉淀为纯函数库、业务语义隔离在内容服务，第二个商场（米制坐标、2,243 节点路网）接入时代码零改动，仅换数据与底图；配套八项数据体检捕获并修复 15 个路网孤岛。
2. **【AI 工程】LangGraph 多工具编排 + 幻觉治理**：意图解析（JSON Schema 约束）→ 数据驱动计划步（工具预算 6 次/12s、去重）→ 跨步骤惰性求值；幻觉后置校验（名单法+回声过滤）宁降级不出错；每步 trace 落库，时延/token 全链路可回放。30 条评测基线首轮 90%（登记 LLM 方差带 77-90%）。
3. **【RAG】自建检索管道**：切片→嵌入→pgvector→重排→阈值→带出处引用；知识文档 CRUD 自动触发增量重嵌（单事务先删后插，失败回滚无检索空窗）。
4. **【生产化】从 demo 到公网**：安全审计 20 项高危分级清零（限流/幂等/越权/防枚举）；6 场景故障演练 16 断言；2C4G 服务器 SHIP 流程（amd64 构建→镜像直传→健康门部署→回滚点）；上线后全项目机器审查 16 根因全部处置。
5. **【工程纪律】测试与台账**：297 后端 + 53 前端测试全绿（CI 双工作流）；缺陷台账每条带复现测试路径；ASSUMPTIONS 登记全部 demo 简化与转生产条件。

## 面试可深挖的三个故事（备讲）

1. **被评测掩盖两周的缺陷**：推荐步骤恒拿空候选——计划步骤在节点入口冻结状态快照，跨步骤依赖必须改为执行期 callable 求值。讲"计划静态、数据动态"。
2. **体检抓住 15 个路网孤岛**：换场景最怕静默降级（某类问句永远失败而无人知）；扶梯/电梯独立点要素不与步行网共享节点，导入器吸附修复。
3. **登录锁定恒 1 秒**：`interval '%s seconds'` 字面量内占位符被 psycopg 转成 `$1` 文本，Postgres 解析为 1 秒——实测传 3600/86400 均得 1.0s。讲"参数绑定的边界"。
