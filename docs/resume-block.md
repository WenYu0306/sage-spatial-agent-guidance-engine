# 简历项目块 · SAGE（复制即用）

## 项目名（一行）

**SAGE — 场景无关的空间智能体导视平台**（个人全栈作品 · 已公网上线）
`sage.westwardecho.com` · `github.com/WenYu0306/sage-spatial-agent-guidance-engine`

## 一句话简介（二选一）

- 完整版：多租户微服务导视平台——6 个后端服务 + 3 个客户端（大屏/手机 H5/运营后台）+ PostgreSQL/pgvector + Docker 公网部署；内置 AI 导览模块（LangGraph 编排 + RAG）作为核心功能之一。
- 精简版：全栈微服务平台（6 服务 + 3 端 + 公网部署 + CI），含 AI 问答、跨楼层路径规划与 RAG 模块；换场景代码零改动。

## 技术栈行

React 19 · TypeScript · Tailwind v4 · FastAPI · Python 3.12 · PostgreSQL/pgvector · Redis · Docker 多阶段构建 · Nginx · GitHub Actions · LangGraph

## 要点（STAR，全栈岗默认排序；投 AI 岗把要点 4 置顶）

1. **【全栈·架构】多租户微服务平台**：15 个包 / 6 个后端服务 / 3 个客户端，契约先行（OpenAPI 生成模型）+ import-linter 强制模块边界 + 多租户每查询租户隔离；架构可移植性经实测——第二个商场（米制坐标、2,243 节点路网）接入时代码零改动。
2. **【全栈·前端】三端体验**：导览大屏（kiosk）、手机 H5（扫码接力落地）、12 页运营后台（自绘组件、无重型框架依赖），统一设计令牌与设计系统；公网三入口全部上线。
3. **【全栈·部署与数据】PostgreSQL + Alembic 0001-0008 前向迁移**；Docker 多阶段构建 → amd64 镜像直传 → 健康门部署 → 回滚点；nginx 安全响应头 + 分区限流；GitHub Actions CI 双工作流（真库迁移 + seed + 前后端全量测试）。
4. **【AI 模块】智能导览**：LangGraph 数据驱动计划步（工具预算/去重/惰性求值）+ 幻觉后置校验（宁降级不出错）+ pgvector RAG 带出处引用 + trace 全链路可回放；30 条评测基线首轮 90%（登记方差带 77-90%）。
5. **【工程纪律】测试与台账**：299 后端 + 53 前端测试全绿；缺陷台账每条带复现测试路径；ASSUMPTIONS 登记全部 demo 简化与转生产条件；第三方审计 P0/P1/P2 项全部闭环。

## 面试可深挖的三个故事（备讲）

1. **被评测掩盖两周的缺陷**：推荐步骤恒拿空候选——计划步骤在节点入口冻结状态快照，跨步骤依赖改为执行期 callable 求值。讲"计划静态、数据动态"（AI 编排）。
2. **体检抓住 15 个路网孤岛**：换场景最怕静默降级；扶梯/电梯独立点要素不与步行网共享节点，导入器吸附修复（数据质量 + 可移植性）。
3. **登录锁定恒 1 秒**：`interval '%s seconds'` 字面量内占位符被 psycopg 转成 `$1` 文本，Postgres 解析为 1 秒——实测传 3600/86400 均得 1.0s（数据库参数绑定的边界）。
